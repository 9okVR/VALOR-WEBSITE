What every player teaches

Features that learn from every VALOR player's scripts, live. No names, no accounts.

How the database works

  1. You play. A script with a database feature keeps a small summary of what happened, like which bey you battled, how it played and whether it won. It never includes your name or account.
  2. The server adds it up. Every hour, everyone's summaries are added together on our server.
  3. Only what holds up is shown. A result appears once enough different players back it up, so one person can't fake it.
  4. Everyone plays better. The scripts read the results back and start from what already works. This page shows the same data.

Auto battle can play three styles. Global Data shows how often each one won against each bey, across every VALOR player. The script starts from this when it picks a style, then learns from your own battles.

Reading the table. Each row is a bey Auto battle fought: its layer, then its disc and driver. How it stays fair

  • Enough players first. A result only shows once 3 or more players on 3 or more networks back it up.
  • No one can flood it. Each player's share is capped, and the result is the middle value across players, so a few fake players can't move it.
  • Nothing personal. Only game results are kept. Nothing here says who played.

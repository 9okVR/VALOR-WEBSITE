The app

A genuine working product

A simple, unique executor that genuinely works. Tabbed scripts, a saved workspace and a console that separates game output from VALOR's own. Write a script, hit Execute, and run it again as many times as you want without rejoining.

  • Tabbed script workspace that persists between sessions
  • Auto-run on join, so your scripts are there before you are
  • Console filters for game output, VALOR and errors

Not just an executor

The VALOR development team does not only build the executor. We write scripts and give them away free, and they ship inside the app in our own first-party hub, ready to run the moment you open it. More info on the Discord server.
